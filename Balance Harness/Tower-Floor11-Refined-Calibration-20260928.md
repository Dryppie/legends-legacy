## Separate fresh confirmation design

A qualifying, independently audited calibration candidate receives a separate **256-seed panel for every one of the 228 combinations: 58,368 fights**. No recipe is discarded because it performed poorly in the historical screen. The same fresh panel is paired across cells, with all historical outcomes excluded from the estimates.

The existing deterministic allocator reserves 256 values in one declared 1/255 block, rejecting the complete historical exclusion union. The full registry is checked under its existing allocation lease before allocation and again after execution. The test runner uses the exact five game assemblies captured by the calibration; rebuilding into a different artifact path does not silently substitute a different executable. Preparation precedes allocation and combat.

For each cell, the existing `TowerBalanceEvaluator.Wilson` calculation supplies an approximate simultaneous 95% Bonferroni-Wilson interval using **all 228 cells** as the family. The independent Python audit calculates the normal quantile separately with `statistics.NormalDist`.

- Every seven-Essence upper bound must be at most 50%.
- At least one seven-Essence lower bound must be at least 10%.
- Every four-/six-Essence upper bound must be below 10%, retaining the exploratory progression-separation requirement.

An observed seven-Essence rate above 50%, an observed control rate at least 10%, or every intended upper bound below 10% yields `Fail`. Evidence satisfying all three interval conditions yields `Pass`; otherwise the complete run is `Inconclusive`. Draws count as nonwins. Low-clear controls are not required to demonstrate viability. No samples are pooled with calibration, no team or setting is reselected, and no additional sample is added after the result. Any conclusion is scoped to this fixed family and captured budget, with approximate interval coverage and no guarantee about unsearched builds.

The confirmation does not change the production boss setting, impose a minimum Essence count or establish a better search algorithm. The repeating equipment curve stays unchanged.
