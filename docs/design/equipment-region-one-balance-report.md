## Replacement and hand-budget caveats

At the candidate next-band factor, Tier 2 rank 0 / Tier 1 rank 5 budget is 1.0417. This is a budget ratio, not a DPS ratio. Current production tier growth and normalized attributes differ; the canonical evaluator must compare real builds before adopting 25%.

A random or guaranteed rank-1 item paid to rank 3 has 30 paid Scrap and returns 15 paid Scrap. A guaranteed copy adds zero base salvage; a random named copy adds 2. Repricing and free starting ranks never increase that paid basis.

Equal per-item rank prices make a two-handed loadout cheaper to improve than an eight-item loadout. The prototype must quantify that difference alongside combined hand budgets and set counts; this report does not silently double two-handed prices.
