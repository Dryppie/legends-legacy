# LegendsLegacy — visual design concept

Four static desktop mockups based on the player UI analysis in [UI_REWORK_ANALYSIS.md](../../../UI_REWORK_ANALYSIS.md). Created 13 September 2026 with the built-in image generation tool.

This direction pairs pale stone and charcoal with large serif identity, restrained vermilion actions, spectral teal Essence art, and fine dividers. Each screen has a composition suited to its player decision.

## Character and build

The character illustration is the focal point. Combat statistics, eight equipment icons, Combat Style, and ordered Essences remain visible together. The ongoing automatic combat action stays in the footer.

![Character and build](C:/repos/Legends-Legacy/legends-legacy/docs/design-concepts/2026-09-13/01-character.png)

## Inventory

A compact equipment list stays beside the selected weapon and its comparison. Positive and negative changes, distinct item properties, and an ownership consequence sit beside the equip action.

![Inventory and comparison](C:/repos/Legends-Legacy/legends-legacy/docs/design-concepts/2026-09-13/02-inventory.png)

## Soul Archive

A selected creature anchors the roster, ability identities, source location, build slot, and Ascension preview. The first occupied Essence slot is explicitly connected to Conduit.

![Soul Archive](C:/repos/Legends-Legacy/legends-legacy/docs/design-concepts/2026-09-13/03-soul-archive.png)

## Active dungeon

An illustrated environment gives the Forgotten Catacombs identity. Revealed route choices connect to the selected encounter briefing. Vigor forecast, pending loot, and retreat are visible together; future nodes remain hidden.

![Dungeon route choice](C:/repos/Legends-Legacy/legends-legacy/docs/design-concepts/2026-09-13/04-dungeon.png)

## Scope and practical considerations

These are visual possibilities, not implemented screens or final gameplay specifications. Player identity, guild name, equipment examples, and numeric values are illustrative. Actual creature names and abilities, Conduit's slot-order relationship, Essence level caps, and the displayed Catacombs route/forecast were informed by the supplied analysis and repository data.

All focal illustrations are newly generated concept art. This is a substantial-art direction: a production version would need an intentional character representation, creature and item artwork coverage, responsive image exports, and accessible font/contrast testing. Dense ability effects and additional attributes would need a fuller detail treatment during implementation; mobile layouts have not been designed or tested here. Concept typography and tiny generated details are not an implementation specification.
