# Emblem

The attribute sign.

**Status:** Draft

Engraved sacred-geometry line art — a star polygon in two rings — that crowns a Folio.

An attribute's Emblem marks it at display size, in the Folio; in rows, comparisons and tooltips the attribute takes its line icon instead, since a five- and a six-point star cannot be told apart at 16px (Foundations · Iconography · Attribute and stat).

**Provide:** `points` (5–12) and `size`. Give each attribute, school or region its own point count so the emblem becomes its sign (Power 6, Crit Chance 5, Resistance 7, Armor 8, Dodge 9).

- Flat strokes in `gilt`; decorative only (`aria-hidden`).
