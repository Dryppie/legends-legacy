# ScreenOverview

The showcase for ArchetypeInformation: the Character Overview.

**Status:** Draft

The Character Overview: everything the current Overview page shows, set in Grimoire and reorganised so the most important facts lead.

**Composed of:** GameShell (chat layout Docked, open) · NavRail (Overview active) · TopBar · Page · PageHeader with SearchField, Search and Refresh · JourneyCard (own profile only) · Banner for the Combat Profile, its body a ProfileIdentity (name with the Nobility crown, Guild and tag, Essences attuned, Achievement Points, Nobility expiry with Show perks) with a LevelPlate (Combat XP) and a StatFigure (Combat Rating) · Panel for the Combat Style (Sigil for Mastery, Mastery XP Meter, Manage link; own profile only) · Panel for the Essence Loadout (LoadoutSlots, including locked future slots) in the side column of an `lg-aside` layout · Combat Attributes as four Ledgers (Offense, Defense, Recovery, Utility) with equipment ratings under Armor and Resistance and an explanation on every row.

Type "Ma" in the search and pick Maren to see another player: presence appears, the journey and Combat Style disappear, and "Back to my profile" replaces Refresh. Values, the guild and ability names are sample content; labels, journey copy and Nobility perks are the game's.
