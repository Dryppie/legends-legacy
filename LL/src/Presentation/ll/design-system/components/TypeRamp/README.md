# TypeRamp

Every type style, by role.

**Status:** Draft

The ramp from Foundations · Typography, set in the four families with real Legend's Legacy words: each style's name, face, size and line height, plus the row line height where a style has one. Above it are the four rules every screen is checked against: the 12px floor, Marcellus from 15px, short capitals and one hero per screen. The styles are built only from the `text-*`, `leading-*` and `tracking-*` tokens.

TypeSpecimen shows the same styles working together on screens.
