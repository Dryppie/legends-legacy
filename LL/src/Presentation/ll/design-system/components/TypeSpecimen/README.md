# TypeSpecimen

The type ramp in use.

**Status:** Draft

Two screens checked against the ramp in Foundations · Typography:

- **Cinder Bazaar.** The PageHeader title is `title-lg`. The "Order book" section title is `title-md` and "Recent trades" is `title-sm`. The item on sale is named in `name-header`, in its rarity colour and with a rarity Tag, followed by its lore line in `lore`. In the order book, the column heads are `label` and every head is three words or fewer. The seller is `name-row`. Quantity, price and total are `numeral-compact`, right-aligned with tabular figures. The expiry is `caption`, and the small Button is `body-compact-strong` in Barlow. In recent trades, each item name is `name-row` in its rarity colour with its `code`.
- **Combat Attributes.** This is an attribute table of four Ledgers. The group heads are `label`, the labels are `body-compact` on the 18px row leading, the values are `numeral-row` and the sub-lines are `caption`.

Neither screen uses `title-xl` or `level-numeral`, because neither is a Folio or a LevelPlate. No number is set in Marcellus.

## Related components

- TypeRamp — every type style
- PageHeader — the screen title
- Heading — the titles
- Ledger — the labelled value list
- Button — the command button
- Tag — the status label
