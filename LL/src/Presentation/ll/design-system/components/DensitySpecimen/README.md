# DensitySpecimen

The three densities side by side.

**Status:** Draft

Foundations · Space & Density, shown on one inventory list and one attribute Ledger in Comfortable, Standard and Compact. Each column states its mode's row height, cell padding, gap, row text, numbers, icon, control height and container inset. Then it shows the same secondary TabStrip, a flush Panel holding seven ListRows, three Buttons and a Ledger of six Offense attributes. The footnote measures the seven rows live: 7 × 48, 7 × 40 and 7 × 32px, plus the two-line rows Comfortable allows.

Compact keeps 14px text, 17px names, 12px meta and whole focus rings; only the air goes.

- ListRow — the list row
- Ledger — the labelled value list
- TabStrip — the tabs
