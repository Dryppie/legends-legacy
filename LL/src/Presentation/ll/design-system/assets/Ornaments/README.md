# Ornaments

- `CornerOrnament.svg` — filigree corner, single ink #F9DCA0 (the game's old primary). Folio uses it as a CSS mask (`cornerSrc`), so it takes the `gilt` ink; flip it for the other three corners.
- `Divider.svg` — the game's existing horizontal divider with a centre diamond, a bronze gradient (#9A7A5F → #EEDEBC), 253×7. Dark grounds only; for new screens prefer SectionRule `ornament`, which follows the theme. Where it is used, it stands in for the ornament rule's lattice and counts as one of the screen's two ornament rules (Foundations · Ornament).
